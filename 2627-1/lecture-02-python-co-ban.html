Python cơ bản cho xử lý dữ liệu

Ôn nhanh có chủ đích: nhìn lại Python bằng con mắt của người làm dữ liệu.

Buổi trước

  • Bức tranh môn học: pipeline từ dữ liệu thô đến kết luận.
  • Chính sách AI: 🔒 đóng / 🔓 mở, ba trách nhiệm khi dùng AI.

Bạn đã học Python ở Tư duy tính toán — buổi này không học lại, mà xem phần nào của Python phục vụ trực tiếp việc xử lý dữ liệu.

1.
Kiểu dữ liệu

Mỗi ô trong một bảng dữ liệu là một giá trị Python — kiểu của nó quyết định bạn làm được gì.

Số và chuỗi: chuyện định dạng

Người đọc báo cáo cần số đọc được — f-string là công cụ hằng ngày:


gia_tb = 1834567.891
ty_le = 0.0734

f"Giá TB: {gia_tb:,.0f} đ — tỷ lệ trống: {ty_le:.1%}"
            

'Giá TB: 1,834,568 đ — tỷ lệ trống: 7.3%'

Hai đuôi định dạng đáng nhớ: :,.0f (phân cách nghìn) và :.1% (phần trăm).

None: "không có dữ liệu" là một giá trị


gia = [1200000, None, 950000]     # phòng thứ 2 không khai giá

sum(x for x in gia if x is not None) / 2
            

1075000.0
Quan trọng None ≠ 0 ≠ "". "Thiếu" là thông tin, không phải số không. Toàn bộ buổi 10 (missing values) dựa trên phân biệt này.

list: dãy có thứ tự — và slicing


doanh_thu = [5, 8, 6, 9, 12, 11, 7]   # 7 ngày

doanh_thu[0], doanh_thu[-1]           # đầu, cuối
doanh_thu[1:4]                        # lát cắt: phần tử 1,2,3
            

[8, 6, 9]

Cú pháp lát cắt [bắt_đầu:kết_thúc] (nửa hở) sẽ theo bạn sang NumPy và pandas — thuộc từ bây giờ, dùng đến hết môn.

dict: một "dòng dữ liệu" tự nhiên


phong = {"id": 52811, "gia": 1200000, "loai": "Entire home"}

phong["gia"]                     # tra theo khoá
phong.get("diem", "chưa có")     # khoá không tồn tại? có phương án B
            

'chưa có'

Một bảng dữ liệu trong Python thuần chính là một list các dict. Đến buổi 4, bạn sẽ thấy pandas sinh ra để thay thế đúng cấu trúc này.

set: khử trùng lặp và so khớp

Hai snapshot dữ liệu — phòng nào biến mất?


thang_9 = {52811, 78230, 99182, 10021}
thang_12 = {52811, 99182, 33307}

thang_9 - thang_12               # có ở T9, mất ở T12
            

{10021, 78230}

Phép trừ, giao (&), hợp (|) trên set là cách nhanh nhất để so hai danh sách ID.

Chọn cấu trúc nào?

Bạn cần… Dùng Ví dụ trong môn
dãy có thứ tự, lát cắt list giá 7 ngày liên tiếp
tra cứu theo tên/khoá dict một dòng dữ liệu, cấu hình pipeline
khử trùng, so thành viên set so ID giữa hai snapshot
bộ giá trị không đổi tuple toạ độ (lat, lon)

2.
Vòng lặp & comprehension

Tư duy "biến đổi cả dãy" là bước đệm sang NumPy.

for + if: máy lọc dữ liệu thủ công


gia_tho = [1200000, -5, 950000, 0, 2400000]

gia_sach = []
for g in gia_tho:
    if g > 0:                    # quy tắc QA đầu tiên của bạn!
        gia_sach.append(g)

gia_sach
            

[1200000, 950000, 2400000]

Comprehension: cùng việc, một dòng


gia_sach = [g for g in gia_tho if g > 0]

gia_trieu = [g / 1e6 for g in gia_sach]     # biến đổi cả dãy
gia_trieu
            

[1.2, 0.95, 2.4]

Cách đọc: "lấy g cho mỗi g trong dãy, nếu…". Câu lệnh ngắn hơn, ít chỗ sai hơn — và đúng cách nghĩ của NumPy: thao tác trên cả dãy, không trên từng phần tử.

dict comprehension & zip


ten = ["Adelie", "Gentoo", "Chinstrap"]
so_luong = [152, 124, 68]

{t: n for t, n in zip(ten, so_luong)}
            

{'Adelie': 152, 'Gentoo': 124, 'Chinstrap': 68}

zip khâu hai dãy song song thành từng cặp — bạn sẽ gặp lại nó thường xuyên khi ghép cột.

Cạm bẫy số 1: gán không phải là sao chép


goc = [1, 2, 3]
ban_sao = goc            # ⚠️ không copy — chỉ thêm tên mới!
ban_sao.append(99)

goc
            

[1, 2, 3, 99]
Cẩn thận Muốn có bản sao thật, dùng ban_sao = goc.copy(). Bug "sửa chỗ này hỏng chỗ kia" sẽ quay lại ở pandas dưới tên view vs copy — gốc rễ là ở đây.

Khi nào dừng viết vòng lặp?

  • Lọc/biến đổi đơn giản → comprehension.
  • Dữ liệu số, cùng kiểu, hàng nghìn dòng trở lên → buổi sau: NumPy xử lý cả dãy bằng một lệnh, nhanh hơn hàng chục lần.
Quan trọng Trong môn này, thấy mình viết for qua từng dòng dữ liệu là tín hiệu để dừng lại và hỏi: "có công cụ cả-dãy nào làm được việc này không?"

3.
Hàm — đơn vị của pipeline

Mỗi bước xử lý là một hàm nhỏ, gọi được, thử được.

Đóng gói một bước làm sạch

Còn nhớ cột giá "$45,647.00" của Airbnb? Ta viết một hàm để làm sạch nó:


def clean_price(s):
    """Đổi chuỗi giá '$45,647.00' thành float; hỏng thì trả None."""
    try:
        return float(s.replace("$", "").replace(",", ""))
    except (ValueError, AttributeError):
        return None

clean_price("$45,647.00"), clean_price(None)
            

(45647.0, None)

Hàm này sẽ theo bạn tới tận bài tập lớn.

Một hàm tốt trong pipeline dữ liệu

  • Một việc: tên hàm nói được việc đó (clean_price, không phải xu_ly).
  • Đoán được: cùng đầu vào → cùng đầu ra; không sửa lén biến ngoài.
  • Chịu được dữ liệu bẩn: nói rõ gặp rác thì trả gì (None? lỗi?).

Docstring một dòng + type hint nhẹ (def clean_price(s) -> float | None) là đủ cho môn này.

try/except: dữ liệu bẩn ném lỗi


float("N/A")
            

ValueError: could not convert string to float: 'N/A'
Cẩn thận Bắt đúng loại lỗi (except ValueError). Kiểu except Exception: pass nuốt chửng mọi thứ — kể cả bug thật của bạn — và pipeline "chạy êm" ra kết quả sai.

Hàm là giá trị: truyền được như mọi dữ liệu khác


gia_tho = ["$1,200.00", "N/A", "$950.00"]

list(map(clean_price, gia_tho))
            

[1200.0, None, 950.0]

Truyền hàm vào hàm khác — bạn sẽ gặp lại đúng pattern này ở buổi 5: df["price"].map(clean_price).

lambda: hàm nhỏ dùng một lần


phong = [{"id": 1, "gia": 1200}, {"id": 2, "gia": 950},
         {"id": 3, "gia": 2400}]

sorted(phong, key=lambda p: p["gia"], reverse=True)[0]
            

{'id': 3, 'gia': 2400}

Quy ước chung: lambda chỉ nên dài một dòng; dài hơn thì viết hàm có tên bằng def.

Vì sao code dữ liệu đầy dấu chấm?

  • Mọi giá trị Python là đối tượng — mang theo phương thức của nó: "abc".upper(), [1,2].append(3).
  • Hãy đọc df.groupby("city").mean() như một chuỗi lời gọi phương thức nối tiếp nhau.

Hiểu đến đây là đủ dùng cho môn này; cách tự viết lớp (class/OOP) xem ở mục Tự học cuối bài.

Module: gom hàm để dùng lại

📖 Tự học
  • import math · from pathlib import Path — dùng thư viện có sẵn.
  • Tự viết cleaning.py chứa các hàm làm sạch → from cleaning import clean_price — cấu trúc src/ của bài tập lớn đúng là như vậy.

4.
Đọc & ghi file

Dữ liệu không nằm sẵn trong RAM — nó nằm trong file, và pipeline phải tự đọc lấy.

with open: đọc văn bản an toàn


with open("ghi_chu.txt", encoding="utf-8") as f:
    noi_dung = f.read()
  • with tự đóng file, kể cả khi có lỗi giữa chừng.
  • encoding="utf-8" phải luôn ghi rõ — tiếng Việt vỡ chữ đa số do quên tham số này.

CSV "bằng tay" — một lần để hiểu


import csv

with open("phong.csv", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

rows[0]
            

{'id': '52811', 'gia': '$1,200.00', 'loai': 'Entire home'}

Để ý: mọi thứ là chuỗi, kể cả id và giá. CSV không mang kiểu dữ liệu — ai đọc người đó tự ép kiểu. Đến buổi 4, pandas sẽ đoán kiểu hộ bạn (và đôi khi đoán sai).

JSON: trao đổi dict giữa các chương trình


import json

ket_qua = {"thanh_pho": "Santiago", "gia_tb": 45647.0}
with open("kq.json", "w", encoding="utf-8") as f:
    json.dump(ket_qua, f, ensure_ascii=False, indent=2)

json.loads('{"gia_tb": 45647.0}')["gia_tb"]
            

45647.0

JSON ↔ dict/list gần như 1-1 — là định dạng chung của API (buổi 6) và cache LLM (buổi 11).

pathlib: xử lý đường dẫn gọn gàng


from pathlib import Path

DATA = Path("data") / "raw" / "santiago"
DATA.mkdir(parents=True, exist_ok=True)
sorted(DATA.parent.glob("*"))
            

[PosixPath('data/raw/santiago')]

Đường dẫn nối bằng / và chạy đúng trên mọi hệ điều hành — cấu trúc data/raw/<city>/ của bài tập lớn viết bằng đúng công cụ này.

Tổng kết

  • None là dữ liệu thiếu; list/dict/set — mỗi thứ một việc.
  • Comprehension = tư duy biến đổi cả dãy — cửa ngõ vào NumPy buổi sau.
  • Pipeline = chuỗi hàm nhỏ chịu được dữ liệu bẩn (try/except đúng loại lỗi).
  • File: with + encoding="utf-8"; CSV không mang kiểu, JSON ↔ dict.

🤖 Làm việc với AI
